At 0.5B/rank-16 the disk path wins ~2× (and that measurement was cache-warm — flattering). At 4B/rank-64 the verdict flips to a 3.4× snapshot win: GPU-CR's 2MB-block amplification shrinks naturally with tensor size (~20× → ~1.6×) while the disk path grows with real bytes through torch serialization, storage bandwidth, and PEFT module rebuild.
